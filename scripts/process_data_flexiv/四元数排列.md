## 结论

本次 profile 显示 Flexiv release 下不同 task 的原始 quaternion 顺序并不一致；例如 `Flexiv_pass_car_0429` 是 WXYZ，而 `Flexiv_clothing_3_packing_0429` 是 XYZW。
因此 `process_data_flexiv_zarr.py` / `process_data_flexiv_double_arm_zarr.py` 后续应增加 task/dataset 级 `raw_quat_order`，在调用 scipy `Rotation.from_quat()` 前按配置转换。
